# 封面文案与题图

> 蛇行于字行之间，见隙乃动。

汉字一格，西文一词，相接空四分：宽则似断，窄则相犯。句读不落行首；距不取负，体不装斜。其所守者，一缝而已：缝对则游，缝失则涩。

## 题图

仓库内的图是导出件：`docs/cover.jpg`，1280 × 853，289 KB。位图原件不进仓库（100 MB 级 PSD 一旦进历史就永久留在包里）。

导出命令（可复算）：

```bash
sips -Z 1280 -s formatOptions 72 cover-v2-1536-v2.jpg --out <repo>/docs/cover.jpg
```

源件在题图库里（`项目题图库/罗蛇Rassarpa/`）：`cover-v2.psd` 与 `cover-v2.ai` 为第二版源件，导出原图有两份——`cover-v2-1536.jpg` 是首版，`cover-v2-1536-v2.jpg` 是现行（2026-11-20 订正西文名用字）。v2 相对 v1 加了青绿／琥珀调色与光晕；v1 只有 PSD，没有 jpg 导出。

**「不允许修改」管的是字库文件，不是平面创作。** 该页「不允许做的事」三条——不得修改或制作衍生版本、不得把字库当商品出售、不得用于违法场景——整组都在讲**字库本身**（改字体文件、出衍生字体、卖字库），不是限制用它的字形做设计。

同页「允许做的事」正好反证，且比上面这条更硬：

- 明列 **VI 标准字**、**商标注册**、全媒体商业发布、出版物、嵌入系统／软件／APP。
- VI 标准字与商标用字按定义就要对字形做调整取舍。若连平面创作里改一笔都禁止，这两条允许立刻自相矛盾。

→ 「罗」字参考甲骨文与现代简体做的取舍，属标题字／VI 用字的正常设计处理，落在允许范围内。**真正被禁止的是把改过的字形做成字体文件再分发**——本仓只出图、不出字体文件，不触及这条。

⚠️ 一处保留：猫啃网那段使用范围是它「按经验整理，仅供参考」，不是作者原始条款原文。日常用不必纠结；若日后要把这枚字标注册成商标、或需要向第三方出具授权背书，按猫啃网的建议直接问字传要一份书面确认，成本很低。

**拉丁名用的是 Kosmos 艺术字**，不是镜像、也不是倒置。这套字的字形本身就长得像反写（R 的斜笔、A 的横画都往左），容易看误；用本机装的 Kosmos 排一行 `RASSARPA` 与图对看，逐个字形对得上。字形由字体决定，改字号、改颜色都不变，⛔ 不必去源件里「翻正」。

v2.1 订正的是西文名的**用字**，不是字形：两版逐像素比下来，差异只落在下方拉丁名的一个字母上（x 537–572、y 791–813），其余不动。

题诗以图上那句为准：「其所守者，一缝而已」。

### Kosmos 的授权核验（2026-11-20）

按 `references/字体授权与合规.md` 的纪律，不凭记忆下结论，回到发布方原文：

| 来源 | 说法 |
|---|---|
| [Behance 项目页](https://www.behance.net/gallery/149176693/Kosmos-Free-Display-Font)（发布者 Pixel Surplus，Alexey Atapin 为共同所有者） | **Free for personal and commercial use** |
| [Pixel Surplus 产品页](https://pixelsurplus.com/products/kosmos-free-display-font) | **Free for personal & commercial use** |
| [Pixel Surplus 授权页](https://pixelsurplus.com/pages/licensing) 的「Personal & Commercial Use License」 | 个人与商业项目**不限次数**使用；限制只有一条：**不得以任何形式再分发** |

→ 按本卷四档，Kosmos 落在 **🔵 可出图**：可作商业图片使用，但**不得再分发字体文件**。仓库只留导出件 `cover.jpg`、不含 `.otf`，正合这条限制。

**两处要留意的反向说法**：`freedesignresources.net`、`actionfonts.com`、`cdnfonts.com`、`font.download` 这几个聚合站标的是「personal use only」。其中 freedesignresources 明说它拿到的是**免费 demo**、「想要完整授权请买付费版」——即聚合站上的可能是 demo 版，与本仓所用不是同一个文件。以发布方（Pixel Surplus）与设计师共同署名的那一页为准，聚合站不作依据。

**仍待确认的一点**：Pixel Surplus 的「Personal & Commercial Use License」只写了「不得再分发」，**没有明写是否允许转成 webfont 嵌入网页**（该限制写在另一档「Desktop Commercial Use License」里）。本仓只出图、不嵌网页，不触及这条；若将来要把 Kosmos 用于网页正文，需另行向 Pixel Surplus 确认。

改图换字前先按 `references/字体授权与合规.md` 查一遍新字体属哪一档。

## 用法

- 首页图宽 720，压在标题与正文之间；⛔ 不放 1536 原图，首屏会被装饰吃掉。
- 社交平台发布时用 1536 × 1024 原图配上面两段文案。
- 改图流程固定：改 PSD → 导 1536 原图 → `sips -Z 1280` → 覆盖 `docs/cover.jpg`。
