# 封面文案

> 蛇行于字行之间，见隙乃动。

汉字一格，西文一词，相接空四分：宽则似断，窄则相犯。句读不落行首；距不取负，体不装斜。其所守者，罗缝而已：缝对则游，缝失则涩。

## 封面图说明（尚未出图）

若要出封面，取一张黑白线稿：一条蛇盘在字行之间，鳞为交叠的方格，线稿透明底。要求三条：

1. 蛇身自粗到细，尾端收成一点 —— 等宽带子不成立。
2. 鳞片可数，且交叠有层次；均匀网格会被看成「设计感」而非「蛇鳞」。
3. 透明底、RGB 全 0、只留 alpha；纸纹不得进入画面。

生成式重绘两次都出等宽带子，形准未达；程序描线在小图上满屏噪点、在大图上把地表枯叶一并描进来。此件留待有透明底原片再作。

## 用法

- 仓库首页不放封面图，免得 200KB 的装饰压在正文之前。
- 发布到社交平台时，用上面两段文案配一张尺寸 1536×1536 的图。
