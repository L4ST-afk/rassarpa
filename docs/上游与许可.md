# 上游与许可

四家上游，两种处理方式：**已并入源码的**随代码走，**会变的数据**只留通道。

| 上游 | 许可 | 用了什么 | 处理 |
|---|---|---|---|
| [赫蹏 heti](https://github.com/sivan/heti)（`sivan/heti`） | MIT | 相邻标点挤压的规则与脚本思路、简体直角引号预设、版式变体的 class 体系 | **已并入源码**进 `tools/cjk_spacing.js`、`tools/cjk-typo.css`；不引入其字体族，不照搬其 `max-width: 42em` |
| [pangu.js](https://github.com/vinta/pangu.js)（`vinta/pangu.js`） | MIT | 部分中↔西边界正则 | **已并入源码**，文件头注明；本仓另有「紧邻全角标点内侧不加」等自有规则 |
| [分寸 · Measure](https://github.com/dososo/blcaptain-measure-cjk) | 代码 Apache-2.0；字体授权数据 CC BY 4.0 | 网页硬规则的编号体系（T01–T19／F03–F06）、「写完就验、最多 5 轮、不偷偷关规则」的纪律 | **只声明，不内置**：`measure.css` 与 `data/licenses.json` 自取 |
| W3C CLReq · GB/T 15834—2011 | 引用 | 标点占位、避头尾、混排间隙的量级（1/4 em） | 引用，不改写条文 |

## 为什么不内置 `measure.css` 与 `data/licenses.json`

字体授权是会变的数据。抄一份快照进仓库，等于把当时那一刻的结论硬化成永久正本：上游改了授权，本仓还照旧的写。所以只留取法：

```bash
npm install -g measure-cjk@0.1.0   # 版本锁死，避开破坏性升级
measure-cjk rules                  # 对齐 SKILL.md §九 的 T/F 编号
measure-cjk fonts "思源黑体"        # 走上游 data/licenses.json，四档
measure-cjk lint <页.html> --render # 360–1440px 六宽实测
```

需要 `measure.css` 的场合，从上游仓库自取，按 Apache-2.0 保留版权声明与 NOTICE；本仓的 `.cjk` 已覆盖同一件事，不取也能跑。

## 编号会漂的地方

`SKILL.md` §九 的括注（T01、T07、F03…）直接对应上游的规则 ID。上游升版或改编号时，这些括注会失配 —— 这是本仓已知的腐化点，核对手法是 `measure-cjk rules` 与本仓 §九 逐条对拍，⛔ 不凭记忆。
