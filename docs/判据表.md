# 判据表

每条一行：主张、取值、成立条件、怎么核验、什么时候失效。**离开条件引用这一行的结论，就是误用。**

| # | 主张 | 取值／表现 | 成立条件 | 核验方式 | 失效条件 |
|---|---|---|---|---|---|
| C1 | 不声明 `text-autospace` 等于关闭 | 与显式 `no-autospace` 差值 0 | Chrome 140+ / Firefox 145+ / Safari 18.4+（三家实现初始值均为 `no-autospace`） | 同一串三对照：无声明／`normal`／`no-autospace` | 引擎把初始值改成规范值 `normal` 的那天 |
| C2 | `normal` 的间隙宽 1/8 em | 32px→4px，64px→8px，比例恒定 | Blink 与 Gecko；WebKit 只在前侧加，宽度同为 1/8 em | 无空格串单边界量 advance 差 | 作者自行改 UA 样式、或引擎换取值 |
| C3 | 带 ASCII 空格的串差值为 0 | 加不加 `normal` 都一样宽 | 规范：已有空格处不再补 | 同一串加空格与不加空格各测一次 | 用 `replace` 语义绕道时（Chromium 未实现） |
| C4 | 四分空（1/4 em）要自己给 | `.mx` 盒 32px→8px = 0.25 em | 需可插 DOM 的场合 | 量 `中X` 与 `中<span class="mx"></span>X` 之差 | 目标媒介不给插 DOM（邮件、第三方编辑器） |
| C5 | 跨元素边界的缝，Chromium 会给 | `中<abbr>a</abbr>中` +8px | Blink、Gecko | 与纯文本同串对照 | WebKit：该处不给（见 C6） |
| C6 | Safari 在元素边界不给缝；每缝包空 span 会把整行原生间隙打掉 | 无间隙 | WebKit（Safari）；WebKit bug 299306 记录 | 本仓未复现，需在 Safari 上跑同一 probe | 已给出跨元素边界修复的版本 |
| C7 | 挤压随字体而定，不看属性支持 | 苹方 −16px；宋体 0；黑体 0 | macOS 三款字体实测；`CSS.supports()` 对三款均 true | `space-all` 与 `normal` 两档同串量差 | 字体本身带 `halt`／`vhal`（思源、苹方系） |
| C8 | 间隙不用字符实现 | 复制文本不含多余字符 | 任何走渲染层的实现 | 复制后粘贴比对 | 用 `U+0020`／`U+2009` 硬插的写法 |

## 两条使用纪律

- **一条结论不能跨条件推广。** C2 在 Blink/Gecko 成立，不等于在 WebKit 成立；C7 在苹方成立，不等于在宋体成立。
- **没跑过的不写成结论。** C6 来自上游 bug 记录，本仓标「未复现」；引用时必须一起引这句。
