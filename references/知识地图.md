## 二、知识要点概要

### A. 字体设计（字形本身）
1. **汉字五大属性**：中宫（结构松紧）、重心（视觉中心高低）、字面（占字面框比例）、字重（笔画粗细）、字怀（笔画间留白）。五者相对独立又互相牵动——**调字重会改变字怀，中宫相对稳定**（像人胖瘦不变骨架）。
2. **字面率**：字面与外框内尺寸的比值，简体中文常见约 **92%**。同字号下字面大的字体，实际看起来更大。
3. **重心不在几何中心**：视觉中心略偏左上；「上紧下松、横细竖粗、左窄右宽」是平衡重心的常用手法。
4. **中西差异**：西文字母宽窄成比例（不等宽），中文一字一格。这决定了版式工作流的根本差异（见 B.1）。
5. **四个基础形状**：方、圆、三角、菱——视觉大小不等，须以最小的菱形为基准统调，否则同字号会显得忽大忽小。

### B. 排版（页面与文字关系）
1. **先算版心，再余白**（中文传统）：行长以「每行 N 个字」定，页边距是页面减版心"余"出来的；西文相反（先定边距）。行长不是字的整数倍时，两端对齐必然导致字距失控。
2. **占字/占行**：段首缩进 `2em`；栏间距「占两个字」；标题高度「占三行」——都是拿正文行做模数。标题占行是正文行的倍数 → 通栏**对行**。
3. **半宽标点的奇偶**：一行偶数个对开标点时行长仍整；**奇数个时把多余半字加在该标点之后**（等效临时全宽），⛔ 不均摊到全行字距——均摊会让该行与上下行字距都不同。
4. **行距**：中文正文 1.5–1.8 倍宽于西文（1.2–1.5），因为汉字字面率高、缺少升部降部形成的天然间隔。
5. **行长**：西文正文舒适区 **45–75 字符**；中文按「每行字数」计，常见 25–40 字。
6. **层级**：相邻层级至少差 4px 或 1.25 倍；一份设计里字重不超过 3 种。
7. **可读性 vs 易读性**：legibility 是单字能否分辨（字怀、x-height 影响），readability 是整段读起来累不累（行长、行距、对齐影响）。两者常被混为一谈。

### C. 历史（解释「为什么长这样」）
1. **宋体不是宋朝的字体**：宋代刻书最初忠实楷书（浙欧、蜀颜、闽柳三系），南宋才逐渐硬化为「横平竖直、横轻竖重、字形方正」——这是宋体的萌芽；明万历成熟，日本称「明朝体」。
2. **仿宋是民国的产物**：1916 年丁辅之、丁善之兄弟为商务印书馆刻「聚珍仿宋」，兼宋楷之长。
3. **黑体是外来户**：源自日本，经中日铅字交流由商务印书馆引进，20 世纪三四十年代大量用于广告。
4. **铅活字两条独立源流**：中国（泥→木活字，雕版仍为主流，因复用性好）；欧洲（古腾堡铅合金＋机械印刷＋油墨＋字库，自成一套）。
5. **中国现代字体设计的三次跳跃**：铅字时代（美华字、611/641 报宋）→ 激光照排（748 工程，1987）→ 屏幕字库。

### D. 应用（落到产物上）
1. **中文字体四个常用体各有岗位**：宋体＝正文；楷体＝低幼读物；仿宋＝公文；黑体＝标题。
2. **中西混排的字族搭配**：中文与西文应有**一致的灰度**（黑度）与**相近的 x-height 观感**，否则一行里中文「发飘」或西文「跳出来」。
3. **打印约束**：细线 ≥0.18mm（喷墨不易断续）、正文字号 8–9pt 时灰度需 ≥60%K、底部不可打印区家用喷墨可达 12.7mm。
4. **字重与字号联动**：小字号不要用 Light/Thin（笔画会断），大标题不要用 Regular（会显弱）。


## 三、西文经典字体个案（来源：The Type 会员通讯 2026-09/10 四封，hello@thetype.com）

> 这批材料解决一个具体问题：**看到一款西文字，怎么判断它属于哪一类、适合什么场合**。
> 全部出自《西文字体：基础知识与用法》2026 版连载，非二手转述。

### 3.1 沿「笔画对比度」这条轴定位（最实用的分类法）

| 阶段 | 代表 | 对比度 | 气质 | 典型用途 |
|---|---|---|---|---|
| 旧式罗马体 | **Garamond**（16 世纪 Claude Garamond 铅字） | 低，粗细过渡柔和 | 诗意、传统、无强烈个性 | 书刊**正文到标题皆可**，适用范围最广 |
| 现代罗马体 | **Didot**（18–19 世纪 Firmin Didot） | **极高**（粗细反差大） | 优美、柔和、时尚 | 杂志标题（《Vogue》即用 Didot）；正文慎用，细笔画在小字号会断 |
| 无衬线（人文） | **Antique Olive**（Roger Excoffon，以法航标识为基础扩展） | 中低 | 现代、明快 | 标识、标题 |

⇒ **可复用判断**：对比度越高 → 越适合大字与标题、越不适合小字正文；这条轴比「衬线/无衬线」更能预测实际效果。

### 3.2 「地域气质」是一个真实存在的维度

The Type 的原话：法国常用字体「比起硬邦邦的德国，更圆润一些」，十九世纪末**新艺术风格（Art Nouveau）**在欧洲遍地开花，**至今仍保留浓重风格的只有法国**。
- 法国线索：Auriol（1900 年发售，海报画家 Georges Auriol，配套装饰花边已数码化）、Arnold Böcklin（新艺术，1970 年前后复刻）、Cochin Italic（小写 d/h/s 带手写般优雅）、Linoscript（**竖直正立**的法式手写体，区别于倾斜的英式铜版手写体）。
- 德国线索：硬朗、几何、低装饰（Bauhaus 一系）。
- **英国线索**（2026-09-12《英国风情的字 #2》）：维多利亚时代是**无衬线体与埃及体（粗厚衬线）**的诞生地——「最大目的就是吸引眼球」，这正是英国风味的来源。代表：Albertus（1990 起伦敦金融城路牌用字；设计者 Bertold Wolpf 生于德国、1930 年代赴伦敦做书籍封面与字体）、Gill Sans（Eric Gill 作品，源自书法家 Edward Johnston 门下；BBC、企鹅出版社标志用字）、Perpetua（Gill 另一作，小写 a／g 来自他 1925 年亲手刻的威斯敏斯特碑文）。
⇒ **用在选字上**：要「柔和/文艺」找法国线索，要「吸引眼球/装饰」找英国维多利亚线，要「严谨/中性」找德国或瑞士线索。这不是玄学，是可命名的风格谱系。

### 3.2b 字体搭配（新增，来自 Perpetua × Gill Sans 的并用）
- **同骨架/同门派的字体可放心搭配**：Perpetua 与 Gill Sans 骨架相近、常并用；这与「字体族（type family）」是同一件事。
- **跨对比度慎搭**：高对比 Didot 配低对比 Garamond、衬线配无衬线，视觉上会打架；不是不能配，是要有明确理由（如用衬线做标题、无衬线做正文）。
- ⇒ 对应到我们的中英混排：**中文与西文应来自「同族气质」**（同为几何无衬线或同为书法骨架），字面率与灰度要接近，否则一行里中文会「发飘」、西文会「跳出来」。

### 3.3 四条容易踩的字体常识

1. **有些经典字体原本只有大写**，小写是后人补的——Banco 原版仅大写，ITC Banco 才由其他设计师配了小写。用老字体前先确认字符集。
2. **手写体通常不能纯大写排版**，但 Mistral、Choc 是例外（休闲风格手写体，可单独用大写）。
3. **「设计者」与「设计指导」要分清**：Vendome 是 Excoffon 做设计指导、并非亲笔，风格上仍是「古典比例＋简洁衬线 → 轻松现代感」。
4. **Peignot（Cassandre）的小写很前卫**，其造型取自公元四世纪「**安色尔体**（uncial）」——大写逐渐潦草、进而演化为小写的那段手写笔法。用它就是在引用一段字体演化史。

### 3.4 复古字体的使用纪律
新艺术/装饰字体（Auriol、Arnold Böcklin、Banco）适合**招牌、标签、包装**这类「有实物语境」的场合；一旦搬到正文或界面，装饰笔画会在小字号糊成一团。⇒ **装饰度与字号成正比使用**。

## 四、信息设计不是中立的（地图案例，来源同上）

The Type 2026-10 那封讲地图，本质是**排版/信息设计的立场问题**，与「网格是否客观」是同一类讨论：

1. **投影即取舍**：墨卡托为航海而画，保角保向，代价是高纬面积膨胀——「格陵兰和非洲一样大」的错觉由此而来（非洲实际是格陵兰的 14 倍）。2026 年 9 月联合国以 164:1 通过决议，建议改用新投影。
2. **「谁在中央」决定认知**：中国版世界地图太平洋居中、欧洲版大西洋居中、美国版把亚洲劈成两半贴在两侧。**每个版本都正确，但每个人脑中的世界不一样**。
3. **「北在上」不是自然律**：中世纪基督教地图东在上（伊甸园在东方），早期阿拉伯地图南在上（朝向麦加）；澳洲曾出版南上地图——翻转 180°，信息一字未改，观感全变。
3.5. **同一批名字，排序规则不同，讲述就不同**（The Type Know「纪念碑上的名字」2026-09-18）：9/11 纪念碑 2983 个名字**不按字母**、按「亲疏关系」（建筑师逐一问家属：你希望你的亲人和谁挨在一起）；越战纪念墙 58000 名按**死亡时间**；南京遇难同胞墙 10665 名按**被确认的时间**分批刻上。碑上用 Optima 镂空。
   ⇒ 与地图案例同源：**版式里的「默认」（谁在中央／按什么排）都在替读者预设立场**。
4. **数字地图的「多重事实」**：同一家服务商按用户所在地显示不同国界与名称，同一产品内并存互相矛盾的版本。

⇒ **对教学物料的启示**：版式里的每一个「默认」（谁居中、什么在上、用什么分类）都在替读者预设立场。做信息图、示意图、地图类素材时，**先问「这个默认是谁的默认」**，再决定要不要打破它。

## 五、检索纪律（避免把好资料搜成骚扰）

- **串行、不并发**：一次一个请求，等结果再决定下一个词。
- **控制总量**：一轮主题检索控制在 3–5 次请求内；同义词替换优先于翻页。
- **先索引后正文**：先拿站点/搜索引擎的结果摘要判断相关性，再决定是否抓全文。
- **抓不到就记缺口**：返回导航层或 403 时如实记录「未获取」，⛔ 不凭记忆补全原文。
- **引用要能回查**：记标题＋日期＋作者＋URL，不写「据说」。
