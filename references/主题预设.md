# 主题预设（吸收自「分寸 · Measure」，有扬弃）

> 来源：`dososo/blcaptain-measure-cjk`，代码 Apache-2.0。
> 本卷只给**气质方向**与**映射到本 skill 令牌体系**的思路；**具体数值以作者上游展示页/仓库为准**，不凭记忆抄死值（主题会演进）。

## 一、6 套主题（分寸自带）

| 主题 | 气质 | 典型媒介 |
|---|---|---|
| **报刊** | 栏宽克制、标题有力、正文疏朗，仿报纸排版 | 新闻/长文阅读 |
| **说明书** | 步骤化、层级清晰、留白充足，强调可读性 | 产品说明书/教程 |
| **档案** | 中性、规整、低装饰，像公文/卷宗 | 表单/台账/记录 |
| **季刊** | 编辑设计感强，图文节奏分明 | 杂志/特稿 |
| **宋刻** | 传统雕版气质：宋体、版心、鱼尾/界行意象 | 古籍/文化类 |
| **分寸** | 项目默认主题，中性现代、留白与层级平衡 | 通用中文网页 |

## 二、映射到本 skill 的令牌体系

本 skill 已有「排版规范与令牌」思路（字号阶梯 ×1.25 但要手调、行高与字号反比、间距 4 的倍数、视觉对齐）。主题预设应**只调令牌，不重写规则**：

- **字号阶梯**：从 §三 的字格模型出发，每个主题定一套「正文/小字/标题」比例（注意 T11 最小字号红线：正文 ≥14px、任何中文 ≥12px，主题不得突破）。
- **行高**：正文 1.6–1.9（T06）；报刊/档案可偏紧（1.6），季刊/说明书可偏松（1.8）。
- **行长**：28–40 字（T05）；报刊/季刊可到上限，说明书/档案可略窄以利扫读。
- **字距**：标题可用 0–0.05em（T07，⛔ 不为负）；宋刻/分寸默认 0。
- **字体栈**：每个主题定一套中文字体栈（T13），并先过 `references/字体授权与合规.md` 的四档红线——🟢/🔵 才能进发布物。
- **标点**：全角 + 直角引号「」（T03/T02），沿用 §三 B 的 `tools/cjk_spacing.*` 做挤压。

## 三、扬弃边界

- 本 skill **不内置 6 套主题的完整 CSS 变量表**——那是分寸项目自带的 assets，会演进。需要时从上游 `dososo/blcaptain-measure-cjk` 的展示页/仓库拉取，再按上表映射到本 skill 令牌。
- 主题只是「气质预设」，**不覆盖 §九 的硬规则**（字距不为负/最小字号/防假斜体/字体授权）——任何主题都得先过这些红线。
- ⛔ 不为「好看」牺牲 T07/T11/T08/F03 等红线；主题调的是层级与留白，不是放宽硬规则。
